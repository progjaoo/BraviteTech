# Tipografia de apoio

Família: **Space Grotesk**, pesos 400 (Regular), 500 (Medium) e 700 (Bold).
Origem: pacote `@fontsource/space-grotesk` **5.3.0**, distribuído pelo Fontsource, https://fontsource.org/fonts/space-grotesk.
Autores originais: The Space Grotesk Project Authors, https://github.com/floriankarsten/space-grotesk.

- `web/`: arquivos WOFF e WOFF2 originais dos subconjuntos Latin e Latin-ext. Os dois subconjuntos estão declarados com `unicode-range` em `../04-web/bravite.css`.
- `desktop/`: TTFs derivados por conversão dos WOFFs e união dos subconjuntos Latin+Latin-ext com fontTools. Cada arquivo contém 552 pontos de código; acentos do português foram verificados. Instale estes arquivos para editar materiais de apoio no Figma, Inkscape e programas locais.
- `OFL.txt`: licença SIL Open Font License 1.1 original, incluída integralmente. A fonte permite uso comercial e redistribuição conforme essa licença. Não vender os arquivos de fonte isoladamente.

As letras da logo aprovada já são curvas vetoriais e não dependem da fonte instalada. Os TTFs servem para títulos e textos das peças; não redigite a logo com a fonte.

Os TTFs são arquivos derivados do kit, não lançamentos oficiais em formato desktop. A família permanece Space Grotesk; a licença distribuída não declara Reserved Font Name.
